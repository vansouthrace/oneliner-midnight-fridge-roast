A one-line roast for the [Midnight Fridge Roast](https://make.fun/bounty/u-carbon-forge-midnight-fridge-roast-fc5d44a7) bounty on make.fun: a smart fridge that refuses to open after midnight, roasted for its petty little rule — the fridge acts like the bill-payer, so it decides when the kitchen closes.

> My fridge locks at midnight like it's the one paying the electric bill.

## Run it

```sh
node main.ts
```

It writes the entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
